# Arsip Dokumen Kylat Google Docs

> [!IMPORTANT]
> **Status**: Arsip non-normatif.  
> **Sumber Kebenaran**: Sumber kebenaran tunggal dan normatif tetap [`spec/`](../../spec/) di repositori ini.

Direktori ini memuat salinan berkas dokumentasi hasil perancangan antara pemilik proyek dengan Claude:
- `01 Aktif (v1.2)/`: Dokumen acuan perancangan konsolidasi v1.2. Salinan `.md` ini adalah bentuk yang dirujuk. Berkas `.docx` tidak disimpan di repo. Sumber asli ada di Google Drive.
  - Dok 1: Visi, Ruang Lingkup, dan Paradigma Komponen Single-File (`*.kylat.php`).
  - Dok 2: Spesifikasi Bahasa Subset PHP v0.
  - Dok 3: Protokol RPC, Keamanan, dan Autentikasi.
  - Dok 4: Arsitektur, Runtime, dan Struktur Komponen `*.kylat.php` (§10).
  - Dok 5: Panduan Adopsi, Alur `kylat dev` (§6), dan Migrasi dari Livewire.
  - Dok 6: Roadmap, Keputusan Desain, Risiko, dan Gerbang.
- `02 Arsip (v1.1)/`: Dokumen arsip perancangan v1.1 (berbentuk `.md`, hasil konversi dari `.docx`).
- `03 Arsip (v1.0)/`: Dokumen arsip perancangan awal v1.0 (berbentuk `.md`, hasil konversi dari `.docx`).
- `template.md`: Format templat dokumen perancangan templat komponen.

Dokumen di dalam direktori ini berstatus **arsip non-normatif**. Jika terdapat perbedaan antara isi dokumen di direktori ini dengan spesifikasi di `spec/`, maka spesifikasi di `spec/` yang berlaku sebagai acuan kebenaran implementasi.
