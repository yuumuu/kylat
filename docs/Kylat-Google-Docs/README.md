# Arsip Dokumen Kylat Google Docs

> [!IMPORTANT]
> **Status**: Arsip non-normatif.  
> **Sumber Kebenaran**: Sumber kebenaran tunggal dan normatif tetap `spec/` di repositori ini.

Direktori ini memuat salinan berkas dokumentasi hasil perancangan antara pemilik proyek dengan Claude:
- `01 Aktif (v1.1)/`: Dokumen acuan perancangan v1.1.
- `02 Arsip (v1.0)/`: Dokumen arsip perancangan awal v1.0.
- `template.md`: Format templat dokumen perancangan.

Dokumen di dalam direktori ini berstatus **arsip non-normatif**. Jika terdapat perbedaan antara isi dokumen di direktori ini dengan spesifikasi di `spec/`, maka spesifikasi di `spec/` yang berlaku sebagai acuan kebenaran implementasi.
